Golden eval set

These are the test questions behind the demo. For each question, the gold answer is the exact book (or books) we expect search to return. We grade each strategy (Lexical, Semantic, Hybrid) by how close to the top it surfaces these gold answers — that's where the hit-rate and MRR numbers come from.
